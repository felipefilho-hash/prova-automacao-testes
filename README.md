
# Automação de Testes com Python e Pytest

Projeto acadêmico desenvolvido durante a graduação em Sistemas de Informação, com foco em Qualidade de Software (QA).

## Objetivo

Praticar testes automatizados e validar o funcionamento de funções em Python.

## Tecnologias utilizadas

- Python
- Pytest
- unittest.mock

## Funcionalidades testadas

1. Classificação de estoque de produtos
2. Inversão de palavras
3. Validação de documentos
4. Geração de códigos e identificação de usuários
5. Verificação de permissões de acesso
6. Atendimento de clientes em fila

## Como executar os testes

Instale o Pytest:

```bash
pip install pytest
```

Execute os testes:

```bash
python -m pytest -v
```

## Sobre o projeto

Este trabalho representa minha experiência prática de aprendizagem em testes de software, incluindo testes parametrizados e utilização de mocks.

Projeto desenvolvido para fins acadêmicos e de portfólio profissional.
